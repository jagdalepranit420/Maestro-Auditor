    📘 Button-by-Button Mastering Guide: BandLab • OBRA • GarageBand (EQ & Noise) Open ▾

    📱 BandLab Step-by-Step EQ & Mastering

    1. Open BandLab → tap + (Create) → choose Import File and load your lossless WAV file.
    2. Tap FX (Effects) at the bottom → tap + → select EQ → Graphic EQ.
    3. Adjust ONLY the bands flagged Yellow/Red in Brain 1 X-Ray using gentle moves (±1.5 to ±2 dB):
    Band (Hz)When to AdjustExact Action
    60–90 Hz (Bass/Kick)Bass feels heavy or masks vocalsPull down -1.5 dB
    250–300 Hz (Mud)Sound feels boxy, muddy, or cloudedCut -1.5 to -2.5 dB
    1–1.8 kHz (Nasal)Vocals sound nasal or honkyGentle cut -1.5 dB
    3–4 kHz (Ear Fatigue)Harsh on repeated listeningGentle cut -1.5 to -2 dB
    6–7.5 kHz (Sibilance)Piercing 'S/Sh' or metallic AI shimmerCut -1.5 to -2 dB
    10–12 kHz (Air/Silk)Track sounds muffled or dullBoost slightly +1.5 dB
    🔥 BandLab Mastering Rule: Use Clarity, Universal, or Tape. AVOID Fire — it over-boosts bass and buries the lead vocal.
    ✂️ 1-Min Drake Pause / Stem Cut Trick: Export Stems (Vocals + Instrumental) from Suno → load both tracks in BandLab → tap Instrumental where you want a dramatic drop → Split and Mute/Delete those 1–2 seconds.

    🔇 Removing Background Noise, Hiss & AI Shimmer

    1. Light Hiss / Hum (BandLab): Tap track menu (⋮) → Denoise, or add FX → Dynamics → Noise Gate with a gentle threshold so natural vocal breaths stay intact.
    2. AI Metallic Shimmer: Cut -1.5 to -2 dB at 6–7.5 kHz in Graphic EQ, or add FX → Dynamics → De-Esser.
    3. Start Clicks / Abrupt Endings: Leave 0.3–0.5s clean silence at start and apply a smooth 2–4s Fade-Out at the end.
    4. Deep Structural AI Noise: EQ cannot remove deep generation artifacts. Use 🛠️ Generate Verified Suno Script → Suno Cover (Audio 75–80% • Style 45–55% • Weirdness 15–25% • Variety 0%) to clean the audio while locking the melody.

    🌐 OBRA Audio (obra.art) — Fast 2-Minute Mobile Polish

    1. Open obra.art in Chrome (Android) or Safari (iPad) — no app install needed.
    2. Upload your lossless WAV file.
    3. Balance the 3 simple sliders using Brain 1 X-Ray:
      • Bass: Lower slightly if bass masks vocals; nudge up if thin.
      • Warmth: Raise gently if harsh/nasal; lower slightly if muddy.
      • Brightness: Raise gently if muffled; keep conservative if sibilant.
    4. Set Loudness to -14 LUFS (Spotify/YouTube) or -11 LUFS (Competition) and download WAV.

    📱 GarageBand (Apple iPad) EQ, Noise & Stem Cut

    1. Open GarageBand → new Audio Recorder project → switch to Tracks View → drag your WAV from Loop Icon → Files.
    2. Tap Track Controls (sliders icon) → Plug-ins & EQ → enable Visual EQ with Analyzer ON.
    3. Make subtle ±1.5 to ±2 dB adjustments ONLY where Brain 1 flagged defects (60–90 Hz bass, 250–300 Hz mud, 6–7.5 kHz shimmer).
    4. For light hiss, use Track Controls → Noise Gate subtly; for Drake Pauses, Split and mute the instrumental stem → Export via Share → Song → Uncompressed WAV.
